# Patterns and blocks

In the editor, open the block inserter, choose **Patterns**, and look for the groups that start with **Basix**. The same patterns are in the group **Basix**.

| Group | Patterns |
| --- | --- |
| Hero | picture beside text, text on a picture, minimal, and the classic hero |
| Features | grid, beside a picture, numbered, features, four steps, process, services list |
| Pricing | three plans, two plans, one offer |
| Testimonials | one quote, three cards, with a portrait |
| Team | three or four people |
| Logos | strip, grid |
| Numbers | three, four, beside a text |
| Call to action | text and button, band, newsletter sign-up |
| Contact | details, with a button |
| Portfolio and pictures | grid, feature, three pictures |
| Blog | latest posts as cards or a list |
| Questions | FAQ, FAQ with a heading beside |
| About | picture and text, values, timeline |

On the development site, `make seed` creates a **Pattern library** page that shows all of them (except the heroes) on one page.

Notes:

- The patterns use placeholder texts and abstract pictures. Replace them.
- The **newsletter sign-up** pattern holds a plain form that does nothing. Replace the form with the one from your newsletter plugin.
- Patterns use only the theme's own colours, so they follow the look you chose and dark mode.

## Block styles

| Block | Styles |
| --- | --- |
| Group | Card, Bordered card |
| Paragraph | Lead text |
| Image | Framed, Soft shadow, Circle |
| Gallery | Masonry |
| Table | Sortable (click a heading to sort) |
| Code | language label, copy button, and colouring for JavaScript, HTML and CSS (add a class such as `language-css`) |

## Page templates

Choose them in the page's settings: **Full width**, **Landing page** (no title, breadcrumb or margins; blocks run edge to edge), **Documentation** (a navigation tree of the section: the top-level page and everything below it), **Calendar**, **Photo gallery**, and **Canvas** (only the content, for page builders).
