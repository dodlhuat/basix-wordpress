A fast, accessible blog and magazine theme built entirely from the Basix component library.

== Description ==

Basix is a classic WordPress theme made from the components of the Basix library (plain CSS and JavaScript, no framework). It includes:

* Light and dark mode that follows the visitor's system and remembers their choice
* Sticky header with an accessible flyout menu on small screens
* Image cards, a hero section and a sidebar with widgets
* Styled comments, password-protected posts, search and 404 pages

== Installation ==

1. In your admin, go to Appearance > Themes > Add New > Upload Theme.
2. Choose the theme zip and click Install Now, then Activate.
3. Create a menu under Appearance > Menus and assign it to the Primary menu location.

== Frequently Asked Questions ==

= Does it need a plugin? =

No. Basix works without any plugin.

= Does it support dark mode? =

Yes. It follows the visitor's system preference, and the toggle in the header lets them choose.
